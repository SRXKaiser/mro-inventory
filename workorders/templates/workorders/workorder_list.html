Guía rápida del flujo Work Order
DRAFT → APPROVED → IN_PROGRESS → COMPLETED | PAUSED | CANCELLED
Estados
DRAFT es borrador. APPROVED queda lista para operar. IN_PROGRESS indica ejecución. PAUSED detiene temporalmente. COMPLETED cierra la operación. CANCELLED cancela y libera reservas activas.
Flujo de material
Primero puedes reservar material para apartarlo. Después haces issue cuando el consumo es real. Si sobró material, registras return para devolverlo al inventario.
Trazabilidad
Cada reserva, issue y devolución queda asociada a la OT. El objetivo es mantener correspondencia entre estado operativo y movimiento real de inventario.
